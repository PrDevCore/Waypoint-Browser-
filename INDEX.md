## ⚠️ Critical Security Notes

1. **Backup Keystore**
   - Store `android/app/waypoint.keystore` securely
   - You CANNOT rebuild your app without it
   - Encrypted cloud storage or USB drive recommended

2. **Protect Credentials**
   - Never commit to git (protected in .gitignore)
   - Treat like root passwords
   - Use Credential Manager for secure storage

3. **One Keystore = One App**
   - Use same keystore for all updates
   - Different keystore = unpublishable update
   - Plan for long-term secure storage

4. **Rotate Passwords**
   - Change periodically in Credential Manager
   - Update environment variables
   - Document changes securely
