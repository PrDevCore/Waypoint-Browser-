📊 BUILD PROCESS
═══════════════════════════════════════════════════════════════════════

What ./scripts/build-release-apk.ps1 does:

  1. Sets environment variables from credentials
  2. Runs: npm run build (builds web assets)
  3. Runs: npm run mobile:sync (syncs to Android)
  4. Runs: ./gradlew assembleRelease (builds with signing)
  5. Verifies APK was created
  6. Shows APK location and size

Automatic signing:
  ✓ Gradle reads environment variables
  ✓ Uses keystore to sign APK
  ✓ No manual signing needed
  ✓ APK is production-ready
